# Feature 公開介面索引

跨功能呈現及領域控制只能從各 feature 的 `index.ts` 引用；頁面組裝不同 feature，feature 不反向引用頁面，共用基礎層保持業務獨立。帳號選單／工作區導航只例外讀取 auth 公開身份及權限契約，沿用既有 ESLint 邊界。

本表登記所有具名公開匯出，包含元件、hooks、schema、型別及 API。實作註解描述介面與生命週期，詳細產品規格見[前端 README](../../README.md)，通用基礎元件見[Shared README](../shared/README.md)。

新增公開匯出時同步登記本表。`npm run check:docs` 直接讀取 TypeScript AST，比對 shared、本索引及 [Profile 元件索引](../pages/profile/README.md)，不載入瀏覽器或執行 API。`npm run check` 包含同一檢查入口。

## 選用與組合

| 情境             | 使用入口                                                                                                    | 設計邏輯                                                                                                                                                                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 私有工作區導航   | `account-menu` 的 `WorkspaceNavigation`、`WorkspaceNavigationToggle`、`useWorkspaceNavigation`              | Profile／Management 使用同一份 sections 與 SESSION 權限；page 提供 active、locale、路由與 handler。1024px 以下重用抽屜，desktop 使用收合 rail，不在各頁複製選單。完整接法見 [ProfilePage](../pages/profile/ProfilePage.tsx) 與 [ManagementPage](../pages/management/ManagementPage.tsx)。 |
| 內容語言         | `language` 的 `LanguageMenu`、`LanguageOptions`、`languageNames`                                            | `variant="text"` 顯示完整語言名稱，`label` 提供獨立 accessible name；介面語言與內容語言由 page 決定，選單不自行寫 URL。busy 仍可選下一語言以取消舊準備；儲存中的 disabled 才鎖定。                                                                                                        |
| 首頁／未送出預覽 | `site`／`journey`／`experiences`／`projects`／`skills` 的 View 入口                                         | Section 負責查詢、View 只呈現已驗證 DTO；草稿透過 showcaseProjection 映射到同一 View，避免重寫首頁版型、詳情與技能展開。                                                                                                                                                                  |
| 本人草稿         | `profile-content` 的 normalized model、`readProfileContent`／`readProfileProjectPage`／`saveProfileContent` | ID record、order、引用及翻譯分開；載入頁面更新 baseline，Save 使用同一 revision 交易。頁面不直接組裝另一種 API body，也不把 local recovery 當保存成功。                                                                                                                                   |
| 管理列表         | `management` 的 `useManagementList`、`updateManagementRecord`、`deleteManagementRecords`                    | parser／query key／write schema／權限集中；page 只組合欄位與草稿。PATCH 送已改欄位及 expected 原值，不能送整份 GET projection。                                                                                                                                                           |
| 即時監控         | `monitoring` 的 `MonitorWorkspace`、`MonitoringPanel`                                                       | HTTP 歷史彙總與 Socket.IO 最新快照分責；流程依 process_uid／request_id 對應，卡片排序不決定 worker 身分。協定及生命週期見 [監控指南](monitoring/README.md)。                                                                                                                              |

以下片段放在既有 page／controller 中，切換策略與資料載入仍由 caller 擁有：

```tsx
import { LanguageMenu } from '@/features/language';
import { ProjectsView } from '@/features/projects';

<LanguageMenu
  variant="text"
  label="Content language"
  locale={contentLocale}
  busy={preparingLocale}
  disabled={saving}
  onChange={changeContentLocale}
/>
<ProjectsView
  locale={contentLocale}
  records={projects}
  total={total}
  hasMore={hasNextPage}
  busy={fetching}
  onLoadMore={loadNextPage}
/>
```

底層元件的 props／焦點／動畫政策見 [Shared](../shared/README.md)；Profile 專用元件及完整組合例子見 [Profile](../pages/profile/README.md)。匯入遵守 `app/routes/pages → features → shared`，跨功能只使用本表入口，避免 private model 相互引用。
